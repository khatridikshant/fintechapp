# Git Remote

**Repository:** https://github.com/khatridikshant/fintechapp

**Clone:**

```bash
git clone https://github.com/khatridikshant/fintechapp.git
```

**Remote name:** `origin`

Set it on a new machine:

```bash
git remote add origin https://github.com/khatridikshant/fintechapp.git
```

**Note:** the repository is named `fintechapp` on GitHub. The application
itself is called `financeapp`. The names differ.
